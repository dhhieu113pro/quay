WSLC containers, without the friction.

Quay is a lightweight Windows desktop interface for managing containers, images, sessions and terminals through your locally installed WSLC runtime.

Everything you need for everyday WSLC work

Stay focused on containers instead of command syntax. Quay talks directly to the WSLC runtime already installed on your machine.

Container managementView running and stopped containers, start, stop and remove them from one clean interface.
Image managementBrowse local images and pull the images you need without leaving the desktop app.
Integrated terminalsOpen container terminals quickly when you need to inspect, debug or operate a workload.
WSLC sessionsSee runtime and session information so you always know what Quay is connected to.
x64 + ARM64Native Windows builds for Intel/AMD PCs and modern Windows on ARM devices.
Lightweight & open sourceBuilt with Rust and Tauri, with source, issues and releases available publicly on GitHub.
